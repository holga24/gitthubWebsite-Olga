Exploratory Data Analysis · Storytelling

Taylor Swift Spotify Analysis

An exploratory analysis project using music data to uncover patterns, build visualizations, and make recommendations.

01 — The Problem

Music datasets contain many audio and popularity features, but listeners need a clear story to understand trends across songs, albums, and listening behavior.

02 — Methods

Python, pandas, exploratory data analysis, data visualization, storytelling, feature comparison, and recommendation framing.

03 — Discovery Findings

The analysis focused on trends in audio features, popularity, album-level differences, and patterns that could explain listener preferences.

04 — Synthesis

I translated numeric audio features into a narrative about style, mood, and recommendation opportunities.

05 — Design Requirements

  • Make patterns easy to scan.
  • Use visuals that support a clear story.
  • Connect insights to recommendations.
  • Avoid overclaiming from exploratory data.

06 — Strategy

The strategy was to clean the dataset, compare meaningful features, create visuals, and organize insights into a readable data story.

07 — Final Composition

The final composition can include charts, recommendation notes, and a short presentation explaining the strongest patterns.

08 — Pivotal Redesign

The project improved by reducing chart clutter and focusing each visualization on one question.

09 — Testing

Testing included data validation, chart checks, reviewing outliers, and comparing conclusions against the source data.
