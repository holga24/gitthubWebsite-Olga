Redlining & Digital Access Analysis

A social-impact data project exploring how historical housing patterns can connect to modern digital access questions.

01 — The Problem

Communities affected by historical redlining may also experience unequal access to digital resources, raising questions about infrastructure, opportunity, and equity.

02 — Methods

API use, geographic or historical data, data cleaning, exploratory data analysis, social-impact framing, and visualization.

03 — Discovery Findings

The analysis focused on geographic patterns, data gaps, and how historical categories may align with modern access differences.

Add maps, charts, or cleaned-data screenshots when available.

04 — Synthesis

I connected historical context with modern access indicators to identify where data could support a clearer equity story.

05 — Design Requirements

  • Make geographic patterns understandable.
  • Explain data limitations clearly.
  • Use respectful language for social-impact topics.
  • Protect community context from oversimplification.

06 — Strategy

The project strategy was to clean and join relevant datasets, visualize geographic patterns, and explain what the data can and cannot prove.

07 — Final Composition

The final composition can include maps, trend visuals, data tables, and a short report explaining access patterns and limitations.

08 — Pivotal Redesign

The work improved by separating historical context from present-day access findings so viewers could understand correlation without assuming causation.

09 — Testing

Evaluation included checking source reliability, validating joins, reviewing missing values, and comparing visual outputs with original data.

10 — Try It

An interactive map or notebook can be added later using public, non-sensitive data.

11 — Results

12 — Contributions

13 — Reflection
